**HealthTrack — Health Monitoring and Shared Trends**

A proposed health monitoring prototype where patients record/import measurements, view trends, and control access for health professionals.

## Proposed implementation direction
- Core: manual entry/CSV import, summaries/charts, patient-controlled sharing, export/deletion.
- Suggested stack: TypeScript + React/Next.js + PostgreSQL.
- Extensions: WHOOP API integration; Apple Health imports; Swift/HealthKit iPhone companion.
- Technology and extension scope remain team decisions; no application code is required for Milestone 01.

Do not commit credentials, access tokens, personal health exports, or identifiable patient data.
