## 4. Project objectives
**Owner: Colby Lumsden**

1. Allow patients to create accounts and securely access their health records.
2. Allow patients to record health measurements manually.
3. Allow patients to import supported health data from a CSV file.
4. Display daily summaries and historical metric charts.
5. Allow patients to grant or revoke a health professional's access.
6. Allow authorized health professionals to review shared patient history.
